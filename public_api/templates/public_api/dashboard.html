Документация

Все методы возвращают JSON. Для рабочих endpoints нужен API-ключ.

Authorization: Bearer sk_stroka_...
GET /api/v1/books/

Список и поиск книг по названию или автору.

q
строка поиска
ordering
-avg_rating, title, -created_at
page_size
до 100
GET /api/v1/books/<id>/

Детальная карточка книги: описание, ISBN, страницы, издатель, язык.

GET /api/v1/authors/

Список и поиск авторов. Подходит для автодополнения и внешних каталогов.

q
часть имени автора
page_size
до 100
GET /api/v1/authors/<id>/

Автор, биография и до 50 его книг из каталога.
